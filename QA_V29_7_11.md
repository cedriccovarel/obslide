# QA V29.7.11 — proxy Zone123 via Apps Script

## Correctif principal
- La slide **Zonage logement social 1 / 2 / 3** peut désormais charger le référentiel officiel **Zone123** via le **même Apps Script** que la source de données.
- Le navigateur ne dépend plus uniquement d’un `fetch` direct vers GitLab DILA / data.gouv.fr.
- Les recherches de communes via `geo.api.gouv.fr` peuvent elles aussi passer par le proxy Apps Script.

## Comportement attendu
- Si la source de données est connectée en mode **Google Apps Script (JSON)**, la slide de zonage utilise d’abord le proxy `/exec?endpoint=zone123` puis `/exec?endpoint=communes...`.
- Si aucun Apps Script n’est connecté, le comportement précédent reste disponible en secours : tentative directe sur les URLs publiques.
- Les curseurs **Textes globaux** et **Textes slide** restent actifs.
