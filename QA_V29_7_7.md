# QA V29.7.7 - zoom regional cartographie departement

## Evolution livree
- Ajout d'un selecteur **Zoom regional** dans les parametres de la cartographie lorsque le niveau d'affichage est **Departement**.
- Choix disponibles : **France entiere** + les 13 regions metropolitaines.
- France entiere conserve le rendu national existant, y compris le zoom Ile-de-France deja present.
- Lorsqu'une region est choisie, la carte est recadree uniquement sur les departements de cette region.
- Les contours departementaux restent visibles et les nombres d'operations sont affiches departement par departement.
- Le panneau de synthese du zoom liste tous les departements de la region avec leurs effectifs.
- En zoom Ile-de-France, les 8 departements sont affiches individuellement : 75, 77, 78, 91, 92, 93, 94, 95.
- Le zoom regional est masque en mode **Region** et la selection est conservee lorsqu'on revient au mode **Departement**.
- L'etat `regionZoom` est stocke dans les donnees de la slide, donc il suit la logique d'instances/duplication existante.
- Les filtres generaux, la connexion Google Sheet, le mode Region, les saisies manuelles et l'export SVG/PNG de la carte n'ont pas ete remplaces.

Seuls deux elements ont ete remplaces pour rendre le test deterministe :
- `localStorage` par un stockage de test en memoire ;
- le chargement du GeoJSON par un GeoJSON synthetique controle.

- Le test navigateur n'a pas utilise le GeoJSON distant reel afin d'eviter une dependance reseau et de verifier le recadrage sur un jeu de geometries controle.
