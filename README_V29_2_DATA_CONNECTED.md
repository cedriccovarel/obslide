# Prestaterre Slide Generator V29.2 — Data Connected

Cette version conserve la V29.1 et modifie le tunnel connecté pour suivre directement la colonne `Évaluation: Statut`.

Les six catégories sont : Non démarrée, Dossier incomplet, Analyse planifiée, Analyse réalisée, Visite réalisée et Évaluation conforme. Chaque statut dispose de sa propre bulle et de son propre drill-down.
