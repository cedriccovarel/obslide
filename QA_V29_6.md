# QA V29.6 — Cartographie Département / Région sur base Google Sheets

Base : V29.5 data_connected.

- Connexion Google Apps Script / Google Sheet conservée.
- Filtre cartographique Département / Région ajouté.
- Les données restent calculées par département depuis la source Google Sheets.
- Agrégation automatique département → région.
- En vue Région, la carte utilise un GeoJSON des régions : les frontières internes de départements ne sont plus affichées.
- Vue Département inchangée avec zoom Île-de-France.
- PNG 4K / export classeur utilisent la vue sélectionnée.
- Clic sur une région en mode connecté ouvre l’explorateur des opérations de cette région.
